## Source and claim discipline

Historical plans, generated memory summaries, source implementation, logged execution and current acceptance are separate evidence classes. Later source can resolve an earlier missing-code gap without proving deployment. An archived log labelled ok can establish that label was recorded, not that its public effect happened. Empty indexed tables do not establish absence of Markdown/vault knowledge.

No raw credentials, USER birth profiles, personal chart values, recipient IDs or session contents are included. Cron errors are reduced to timeout/delivery/other categories; these are approximate categories, not root-cause diagnoses. SQLite stores were opened read-only for schema/counts only. Installers and archived code were never executed. Standard library inspection code ran outside the archive.
