## 2. Core thesis

Consecration is not decoration of an object; it is the engineering of a **shared attention anchor**. The ritual takes an inert, carefully proportioned substrate and, through an ordered sequence of operations, installs it as a stable point that a community’s attention, emotion and expectation keep returning to. Read through dynamical systems, the murti becomes an **attractor**: once installed, belief flows toward it and is reinforced by it.

## 3. Protocol architecture (from the study guide)

| Phase | Traditional name | Systems reading |
|---|---|---|
| 1. Substrate preparation | Murti śuddhi | Initial state configuration — tala proportions, mudra as signal encoding, material, orientation (vastu), creation muhurta |
| 2. Field clearing | Śodhana | Entropy reduction — clear residue, establish baseline coherence |
| 3. Invocation | Āvāhana | Address the target pattern — call the archetype |
| 4. Life-force transference | Prāṇa-pratiṣṭhā proper | Install — couple archetype to substrate |
| 5. Stabilization | Ongoing worship | Maintenance loop — daily rites keep the attractor deep |

**The closed loop (the most defensible idea here):**

- Archetype → idol: the pattern is given a physical anchor
- Idol → devotee: a sensory interface — seen, touched, circumambulated
- Devotee → archetype: attention and devotion flow back

Each leg reinforces the others, so the system becomes self-sustaining. That is a real model of how shared belief persists.

**Failure modes:**

- *Visarjana* — intentional deactivation (e.g. Ganesh Chaturthi immersion): the reverse protocol, run on purpose
- *Neglect* — rites stop, the loop loses energy
- *Desecration* — violent disruption of the loop
- *Loss of belief* — the collective basin flattens

**The I Ching layer:** diagnose the current state with a hexagram, choose the matching transformation operation, install, then re-cast to verify the change. As a *WitnessOS design pattern* (diagnose → prescribe → install → verify) this is useful regardless of whether the 64 = 64 correspondence holds.
