## A sustainable activity loop

Prepare one concrete example from the work each week: a screenshot with its context, a before/after passage, a small design decision, or one question that remains open. Verify any release or availability claim against current evidence.

Use X for the compact idea. Expand an idea when a specific reader question, useful disagreement or clearer argument warrants it. The two already-prepared essay weeks are a deliberate starting sequence; their readiness does not imply X signal has already been observed. Instagram translates a distinction visually; Reddit starts from a community question and stands alone.

Propose three brief reading windows each week, capped at fifteen minutes. Select up to three conversations where a specific contribution would help. Prepare replies only after reading the target; every public reply needs its own approval. No quota for comments, automatic likes, generic praise or link drops.

Keep the existing weekly preparation, daily approved-item check and bounded Sunday maintenance. Maintenance failures should hold only the affected channel. Continue writing while that channel is held. No additional recurring job is necessary for this package.

## Approval and account changes

Review profile fields together as one exact change set per account. Public posts stay individually approved under the existing policy. Record the approved copy, account, destination, media hashes, dates and delivery settings. Changed wording invalidates that approval.

Refresh account identity and duplicate history before submission. Browser work uses IAB only; there is currently no IAB control tool in this session. A saved browser session or cookie file is not submission proof. Private composer drafts can be created when that control returns; public publication still waits for exact approval.

A native future schedule is a scheduled state with its own platform receipt; it must not be recorded as published. If that state is not supported by the ledger, use approved due-date publication and confirmed readback instead.
