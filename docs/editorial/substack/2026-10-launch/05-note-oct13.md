# Leave the intention unfilled

“Can we talk tomorrow?” is a message. “They’re unhappy with me” is an interpretation of that message.

The interpretation might be right. Keeping it separate does not dismiss it; it gives later information somewhere to arrive.

A useful record can contain “I don’t know yet.” It can also contain “I don’t remember the order.” Neither gap needs to be repaired with confidence.

Thursday’s essay offers five fields for an ordinary event. The aim is a description particular enough to be corrected.
