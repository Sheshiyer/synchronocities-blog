# Recognition and return

A small, optional companion to *The Answer After Recognition*. Use an ordinary, low-stakes situation if this is useful; skip it or stop whenever you prefer. Keep personal details private. This is an observation prompt, with no promised effect.

**The encounter:** What happened? Record the words or event you actually noticed. Keep an interpretation separate from the description.

**The recognition:** What did it resemble? Which name arrived first? What could that name leave out?

**The possible answer:** What response came to mind? Was another response available? An imagined answer remains a possibility until chosen and performed.

**The choice:** What did you actually do, if anything? Choosing no new action is allowed. Do not manufacture an experiment to fill this space.

**The return:** What followed? What remains unknown? If the consequence has not arrived, write “pending.”

**The revision:** Does the return preserve, complicate or change the initial reading? What question should remain open for another encounter?

You can keep the first reading alongside the later one. Revision need not erase the earlier record. No result has been collected or assumed by this companion.
