# References

_Save clips you love into this folder with plain names (travel-edit.mp4, captions-style.mp4)._
_Then add timestamped notes below: one ## heading per clip, notes in this format:_
_`- mm:ss-mm:ss · what happens on screen · why I like it`_

_Run `npm run refs` to extract contact sheets for every timestamp._

## Never do

_Techniques you have seen and actively dislike. One line each._

- Text that bounces or wiggles on arrival
- Fast-shaking camera moves
- Cluttered frames with more than two elements moving at once
