# Organic project discovery

Reader path: a useful idea or exchange → recognizable series → complete essay/archive → a relevant project demonstration → voluntary exploration of tryambakam.space.

## First twelve weeks

| Period | Editorial purpose | Project bridge |
|---|---|---|
| Weeks 1–4 | Reintroduce the inquiry through runtime, pattern log, body and a lived arrival. Establish voice through substantive replies and Notes. | Source footer to Synchronocities; occasional profile/hub reference to `https://tryambakam.space/`. No sales pitch in comments. |
| Weeks 5–8 | Speech, type pressure, symmetry and ritual. Use reader questions to choose examples. | A checked visual/model demonstration where relevant. Verify current engine/atlas capabilities before naming them. |
| Weeks 9–12 | Intervention, intelligence, breath and narrative. Make one honest process/demo piece. | One clearly affiliated project field report; only link the working flow actually inspected. |
| Thereafter | Rotate the nine series; respond to real recurring questions and revisit useful works. | One project field report monthly; prioritize reader need over presenting every project. |

## Topic-to-project routing

| Topic | Appropriate destination | Evidence before linking |
|---|---|---|
| All editorial strands | `https://synchronocities.tryambakam.space/` | Specific source article returns/rendered successfully; source revision recorded. |
| Framework overview / request for project map | `https://tryambakam.space/` | Current rendered site, accurate short description; follow its current project links instead of guessing slugs. |
| Geometric/symbolic systems or developer methods | Selemene current public destination discovered from the hub/capability ledger | Verify intended reader flow and capability; old 16-engine brand count is not current evidence. A health endpoint alone is not a useful reader destination. |
| Narrative, body, creative practice | Current Somatic Canticles destination discovered from the hub/canonical manuscript | Verify current edition and readable entry flow. `1319.tryambakam.space` previously named in brand copy needs current flow review: retrieved page differs from older 27-chapter/no-signup copy. |
| Human judgment and tools | Current witness/agent demonstration, if the hub exposes it | Working public flow and honest scope; do not imply unreleased capabilities. |

For atlas/selemene sites, the web reader could not verify reachability on 2026-09-30; that is not proof of downtime. Hold outbound links until a current check succeeds. For every project receipt record URL, date, observation, capability demonstrated and limitations. Separate design intent from live availability.

## Channel form

Substack essay: complete 900–1800-word argument when appropriate, one meaningful image, source links, one reader question. Notes: one small complete thought; a source link only when helpful. X short posts: one proposition/example/question in account-supported length. X Articles: 600–1200-word standalone argument with verified visual and source footer, every other week as capacity allows. Comments: usually 60–140 words, anchored in the author's exact argument, normally link-free. These are editing ranges, not output quotas.

Do not reuse the same paragraph across authors. Do not force a project mention into a discussion about somebody else's argument. Affiliation may be phrased plainly: “In my own work on …”. Measure reader interest through voluntary next steps, not manufactured reciprocity.
